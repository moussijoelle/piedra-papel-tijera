# Piedra, papel o tijera

Mini juego contra la máquina: eliges 1, 2 o 3 y comparas con un número aleatorio.

## Qué hace

- Introduces 1 (piedra), 2 (papel) o 3 (tijera)
- La máquina elige al azar
- Muestra empate, victoria o derrota
- Si el valor no es válido, cierra con un mensaje de despedida
- Incluye guía en `guia-ejercicio.html`

## Cómo probarlo

Abre `index.html` o la demo (hace falta JS en el navegador).

Demo: https://moussijoelle.github.io/piedra-papel-tijera/

## Cómo lo construí

- HTML + JavaScript + Tailwind (browser CDN)
- Lógica en `app.js` (validación, reglas y texto del resultado)
- Estilos base en el propio HTML

## Cómo verificarlo

Sin tests. Pruebo las tres opciones, un empate forzado jugando varias veces, y un valor inválido.
